# Videogame Recommender

Streamlit web application that recommends videogames using Steam data. The project includes interactive filters, search functionality, and recommendation logic based on similarity using Python, Pandas, and Scikit-learn.

## Features

- Interactive filtering by game characteristics
- Search functionality
- Recommendation logic based on similarity
- Data processing and cleaning with Pandas
- User-friendly interface built with Streamlit

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Streamlit

## Project Structure

- `src/` -> main application files
- `data/` -> datasets
- `models/` -> saved models or recommendation assets
- `README.md` -> project documentation

## How to Run

1. Clone this repository
2. Install the required libraries
3. Run the Streamlit app

```bash
pip install -r requirements.txt
streamlit run src/streamlit_app.py
